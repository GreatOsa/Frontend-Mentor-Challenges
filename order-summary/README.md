# Order Summary Component

This is a solution to the [Order summary card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/order-summary-component-QlPmajDUj).

## Overview

A responsive order summary card component built with HTML and CSS. This project showcases a modern design for displaying subscription plan details and payment options.

### Features

- Responsive design
- Interactive elements

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
